# OppenCouncil 5.0.0

5.0.0 将普通与科研项目接入统一的 `oppencouncil` skill，两个旧名称继续作为兼容入口。项目类型显式声明，科研流程不再由 R 语言或目录布局决定。

- 调查、证据、推荐、反馈进度与人类审阅构成同一工作流程。依据变化而正文不变时，在当前版本追加重新确认记录。
- 正式产出绑定已确认的规格与可核验来源；工作台支持可编辑表格和保存在 `Freeze/assets/` 的不可变图片副本。
- Decision Memory 使用已确认的唯一文本基线，读取两种旧格式。科研新条目要求 `basis`，普通项目可选；关系状态和反向链接由 helper 管理。
- MCP 可读取已授权治理信息、提交证据和参与讨论。外部 MCP 不创建正式问题或候选，也不代替人类确认。
- 安装器接入统一 skill 与两个兼容名称；Council 和 MCP 使用相同的 5.x 存储实现。

## 已有安装

软件更新不会迁移项目。现有 v3/v4 项目继续由原 helper 实现处理；v5 转换需要单独明确授权，并使用检查后应用的迁移计划。保留原配置、项目登记、OAuth 授权及服务标识。

完整源码安装包为 `OppenCouncil-5.0.0.zip`；Council 组件另提供 wheel 和源码分发包。按根目录 README 安装；已有 MCP 安装继续使用 `scripts/install.py --with-mcp`。

## 发布验证

最终版本在本地完整产品验收中通过 Council、skills/integration、网页单元测试和 MCP 检查；具体执行记录由发布附件外的本地验收日志保留。发布以同一提交在 GitHub Actions 的 Linux、macOS、Windows × Python 3.12/3.13 六种组合全部通过为门槛。

早期分阶段及独立行为评测的结果与限制见 [开发验收记录](v5-acceptance.md)。这些评测不等同于真实科研分析的科学有效性验收。
