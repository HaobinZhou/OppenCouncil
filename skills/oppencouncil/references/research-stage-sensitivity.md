# Sensitivity and subgroup analysis

Current supplemental tables and figures are registered through the same `result` interface and confirmed specification bindings as main outputs. `index TARGET` locates their owners and producers. Related definitions can be read individually with `python -m oppencouncil definition TARGET --question F-NNNNNN`.

An experiment's registered question, scripts, outputs and status are read with `explore index TARGET`. Creation, promotion and archival use checked plans; [project-operations.md](project-operations.md) describes those payloads. `review list TARGET --actionable` lists unresolved work whose continuation condition is ready, without treating archived experiments as current work.
