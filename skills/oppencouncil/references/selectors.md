# Inline discussion choices

Syntax: `{{choice:stable_id;label;value1;value2}}`, outside code formatting in discussion or comparison text. Use 2–12 distinct nonempty values and a stable ASCII ID starting with a letter. Fields cannot contain braces, newlines or semicolons. An ID identifies the same parameter with identical label and values within its question/group.

The widget stores a browser-local preference. “添加到讨论” creates an editable message that the human then saves. It does not recompute candidates, enforce dependencies or confirm a definition. Normative candidates use concrete proposed values. Group option payloads are in [groups.md](groups.md).
